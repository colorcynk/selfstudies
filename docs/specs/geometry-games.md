# 背景と目的

既存の「まなびのゲームひろば」に、図形を題材にした5つ目のゲームを追加する。仮称は「ずけいたんけん」。九九モンスターが九九を覚える入口であるように、図形の名前・特徴を知る入口と、それを使って図を観察する遊びを用意する。

初版には次の両方を含める。

- 基本編「おなじかたち」：見本と同じ形・同じ大きさの図形を選び、正解後に名前と特徴を学ぶ。
- 応用編「いくつある？」：図の中に指定した種類の図形がいくつあるか答え、正解後に数え方を確かめる。

基本編は回転を許し、拡大・縮小は許さない。応用編では、指定された種類に該当する図形を大きさ・向きによらず数える。この違いは、それぞれの開始前に例と短い説明で伝える。

# 利用者と成功の目安

- 既存アプリと同じく小学2〜3年生を中心に、保護者の補助も想定する。学年による利用制限は設けない。
- ホームから両モードを選び、説明、回答、ヒントと再挑戦、解説、結果、収集を一通り利用できる。
- 間違いへの罰則、残機、制限時間を設けず、自分のペースで遊べる。
- 正解を覚えるだけでなく、「何が同じか」「どの輪郭を数えたか」を画面で確かめられる。
- 本仕様は学年内容の網羅や学習効果を保証しない。

# 承認済みの範囲

ユーザーが確定したのは、両モードを含めること、基本編では回転を正解・大きさ違いを不正解とすること、題材を下記の6つとすること。応用編もこの6題材の範囲とし、正三角形・二等辺三角形・直角三角形のいずれにも当てはまらない三角形は含めない。

具体的な9ステージ・各5問、4択、解説操作、収集と保存を含む本書全体は、2026-10-15のユーザーの「承認」により採用済み。この仕様に基づいて実装計画を作成する。

# 初版の範囲

## 図形の題材と教材表現

基本編では、円・正方形・長方形・正三角形・二等辺三角形・直角三角形の6つを題材にする。これらは排他的な分類ではなく、学習の題材である。

| 題材 | 正解後に伝える特徴の要旨 |
| --- | --- |
| 円（まる） | 真ん中からふちまでの長さが、どの方向でも同じ |
| 正方形 | 4つの辺の長さが同じで、4つの角が直角 |
| 長方形 | 4つの角が直角 |
| 正三角形 | 3つの辺の長さが同じ |
| 二等辺三角形 | 2つの辺の長さが同じ |
| 直角三角形 | 直角を1つ持つ三角形 |

学習指導要領解説の図形の定義を根拠に、画面ではひらがなやふりがな、辺・角の強調表示を使って説明する。円、二等辺三角形、正三角形は3年生の学習内容に含まれる。[^mext-mathematics]

正方形も長方形の条件を満たし、正三角形も二等辺三角形の条件を満たす。直角二等辺三角形は直角三角形と二等辺三角形の両方の条件を満たす。これらを「必ず別の仲間」とは説明しない。基本編は種類名を当てる問題ではなく、見本との形・大きさの一致を選ぶため、条件が重なる種類を別解扱いにする必要はない。応用編では、指定された種類の条件を満たすかで数える。

二等辺三角形のステージの見本には正三角形でないもの、長方形の見本には正方形でないものを使い、各題材の特徴を見分けやすくする。直角三角形との重なりを否定する説明はしない。

## ステージと問題数

| モード | ステージ | 問題数 |
| --- | --- | ---: |
| 基本編 | 6題材ごとに1ステージ | 6 × 5 = 30問 |
| 応用編 | はじめのかぞえかた・くみあわせ・まざったずけい | 3 × 5 = 15問 |

- 全9ステージ、独自に作成した固定45問を同梱する。実行時のAI生成や、未検証の図の自動生成は行わない。
- 1回は選択したステージの5問。初版は教材上の順序を固定し、同じ回に同じ問題を重複出題しない。
- 両モードと全ステージを初めから選べる。基本編のクリアを応用編の利用条件にしない。
- 同じステージは何度でも練習できる。

# 基本編「おなじかたち」

## 遊び方

1. 題材のステージを選ぶ。
2. 見本と4つの候補を見比べ、同じ形・同じ大きさのものを1つ選んで答え合わせする。
3. 間違えたら、同じ問題でヒントを見て選び直す。
4. 正解後に名前・特徴と、見本との一致を示す解説を見る。
5. 「つぎへ」で進み、5問目の解説を終えて結果を見る。

## 照合と描画の条件

- 位置を移動し、回転して見本にぴったり重なる候補が正解。拡大・縮小や変形を必要とする候補は不正解。
- 裏返しだけで一致し、回転では一致しない図形は不正解。左右反転した見た目でも回転で重なる図形は正解の条件を満たす。
- 正解は各問に必ず1つ。図形の対称性によって複数の候補が同じ正解にならないことも教材検証で確認する。
- 円以外の各ステージに、回転した正解と、大きさだけが異なる不正解を含める。円には半径の異なる不正解を含める。
- 各問に少なくとも1つ、大きさだけが異なる不正解を用意する。他の不正解には縦横比・角・辺の関係が異なるものも使える。
- 見本と全候補は共通の座標尺度・同じ大きさの描画枠を使う。図形ごとの自動フィットで大きさの違いを消さない。画面が狭い場合も枠同士の尺度を揃える。
- 円を楕円にするなど、画面幅によって図形を変形させない。回転後も輪郭が切れない余白を確保する。
- 色、線の太さ、枠の強調や選択肢名だけから正解が分からないようにする。
- 子どもに定規で測る操作を要求せず、大きさ違いはスマートフォンでも見分けられる差を付ける。

## 解説

- 回答前には正解の候補や一致の輪郭を示さない。
- 誤答時は「むきをかえて かさねてみよう」「おおきさも みてみよう」などのヒントを出す。
- 正解後は、正解の候補を見本と同じ向きにした重ね合わせと、題材の名前・特徴を表示する。円は回転表現を必要としない。
- 図形の特徴は、辺や直角などを文字と図で示す。自動再生のアニメーションは必須にせず、静止画でも理解できる表示にする。
- 問題の正解後には必ず解説段階を置く。最後の問題も解説を飛ばして結果画面へ遷移しない。

# 応用編「いくつある？」

## 指定する種類と難易度

初版で扱い、数える対象にするのは、基本編と同じ円・正方形・長方形・正三角形・二等辺三角形・直角三角形の6つ。「三角形全体」を指定して数える問題は設けず、問題文では「せいさんかくけい」「にとうへんさんかくけい」「ちょっかくさんかくけい」のように種類を明示する。

正三角形・二等辺三角形・直角三角形のいずれにも当てはまらない三角形は、正解にも、対象外の図形としても出題図に含めない。線の交点や複数の領域の組み合わせによってできる大きい三角形もこの制約の対象とし、教材確認では対象の種類以外の三角形も点検する。

| ステージ | 内容と完成条件 |
| --- | --- |
| はじめのかぞえかた | 離れた輪郭の図形から指定した種類を選んで数える。6題材のうち指定した種類に該当しない図形が混ざる問題と、答えが0の問題を含む。円を数える問題はこのステージに配置する |
| くみあわせ | つながった線でできた図を観察し、小さい図形と、それらを組み合わせた大きい図形を数える。2×2の正方形格子の答えが5になる問題を必ず含める |
| まざったずけい | 対象範囲内の三角形と正方形・長方形が混ざり、内部の線や共有する辺を持つ図から指定した種類を数える。単に離れた図を並べるだけの問題にはしない |

- 全15問の中に、6題材それぞれを指定して数える問題を1問以上含める。各応用ステージには、正方形または長方形を数える問題と、対象範囲内の三角形の種類を指定して数える問題をそれぞれ含める。
- 少なくとも1問は、向きの異なる図形も対象になることを確かめる。
- 正解の個数は0〜20。小画面でも輪郭を読み取れる密度に制限する。

## 数える規則

- 描かれている線で輪郭が完全に閉じている、指定された種類の図形をすべて数える。
- 種類の条件は包含関係も含めて適用する。長方形を数える問題では正方形も、二等辺三角形を数える問題では正三角形も含める。直角二等辺三角形は、二等辺三角形を指定した問題でも直角三角形を指定した問題でも数える。該当する重なりがある問題では開始前の説明・ヒント・正解後の解説で、その数え方を明示する。
- 大きさや向きは問わない。大きな図形の内部を線が通っていても、外周が成立していれば数える。
- 同じ辺を複数の図形で共有してよい。複数の小さい領域からなる大きい図形も数える。
- 同じ輪郭は1回だけ数える。頂点を数える順番や辺の分割方法が違っても別の図形にはしない。
- 線のない部分を想像してつなぐ、途切れた線を補う、厚み・色・飾り・文字を辺とみなすことはしない。
- 円は独立した閉じた輪郭として配置する。円以外の出題図は有限本の直線分で構成し、円・曲線が他の図形と交差して新しい輪郭を作る問題、立体、遠近法、隠れた辺の推測は含めない。
- 例の2×2正方形格子では、小さい正方形4つと外周の正方形1つで5つ。長方形の領域は追加の正方形として数えない。

## 回答と解説

- 個数を数字入力し、画面内の数字ボタン・キーボードの両方で答えられる。未入力と0を区別し、小数・負数・数字以外は回答として受け付けない。
- 誤答では、大小で分けるなどの方針をヒントとして示し、同じ問題で再挑戦する。答えの個数や全輪郭の一覧は正解前には示さない。
- 正解後に、数えた輪郭を1つずつ番号付きで強調して確認できる。前後の輪郭を選ぶ操作はキーボードでも利用できる。
- 合計と、「小さい正方形4つ、大きい正方形1つ」のような内訳を文章でも示す。0個の問題では該当する輪郭がない旨を説明し、輪郭を切り替える操作は出さない。
- 最後の問題を含め、解説を見てから明示的に次へ進む。

# 共通の体験と記録

- ゲーム内にモード・ステージ選択、遊び方、出題と解説、結果、発見カード帳を設ける。ホームから入り、ホームに戻れる。
- 全5問に正しく答え、最後の解説から結果へ進むとステージ完了。完了時点でだけ履歴とカードを保存する。
- 結果には初回正答数／5、完了したステージ、獲得カードを示す。再挑戦後の正解を初回正解に数えない。空欄・不正な入力は回答試行として扱わない。
- 各ステージに発見カードを1枚、合計9枚用意する。基本編6枚は図形の特徴、応用編3枚は数え方の振り返りを記す。
- 同じステージの再クリアで同じカードを重複獲得しない。再練習の完了履歴は追加できる。
- カード帳で獲得済みカードと説明を再確認でき、未獲得のカードは未獲得と分かる表示にする。
- 途中でやめる・別ゲームへ移る・再読み込みする場合、その回の途中状態は保存せず、未完了の報酬・履歴も追加しない。完了済みの記録は残す。
- 回答、次へ、結果へのボタンの連打やキーの長押しで、問題・解説を飛ばしたり記録を二重追加したりしない。

# インターフェース・データ・互換性

- 既存のReact・TypeScript・Viteアプリに追加し、ホームの5枚目の入口と専用のハッシュルートを設ける。
- 問題は安定したID、ステージ、見本・候補または直線分と独立した円による図、正解、ヒント、解説を持つ。応用編は指定する種類と、正解を構成するすべての輪郭をデータとして持つ。
- 基本編の採点は、種類名だけでなく、形・寸法と回転による一致の条件に対応する。応用編の正解数は解説用の輪郭一覧と一致させる。
- 図形の描画・教材データと採点・進行処理を分離し、描画と解説で同じ幾何データを使う。
- 既存の完了記録APIとカタログを拡張する。発見カードは既存の宝物区分へ新しい専用IDで登録し、既存のモンスター・スタンプ・漢字の宝物とは区別して表示する。
- 保存キーと形式バージョン1を維持し、追加前の4ゲームの保存データをそのまま読み込める。既存のIDや履歴・報酬・自己ベストを失わせない。
- 共通ホームの収集総数に図形のカードも含める。漢字の宝物帳には図形のカードを混在させない。
- 履歴は共通の直近50回。保存不可・破損・未知バージョンへの対応、保護者向けの全記録リセットは既存の契約に従う。
- 旧アプリ版で追加後の保存データを開く逆方向の互換性は保証しない。公開後の切り戻しでは新しい記録を旧検証処理で読み込む問題を考慮する。

# アクセシビリティ・品質・運用

- 幅375px・768px・1280pxで、見本と候補の尺度が一致し、図形が欠けず、主要操作に横スクロールを要求しない。
- 主要操作は44px以上、選択肢・入力・輪郭切り替えに名前を付ける。Tab・Enter等で回答、再挑戦、解説確認、結果まで操作できる。
- 選択中・正誤・輪郭の番号を色だけで伝えない。画面遷移時のフォーカスとフィードバック通知を確認する。
- 図形問題は視覚的な比較を中心とする。正解の種類名や正解位置を回答前の読み上げラベルで漏らさない。完全に非視覚の代替問題は初版の範囲外とする。
- 動きを減らす端末設定を尊重する。自動的に次問へ進めず、解説は時間制限なく確認できる。
- 図形とカードは同梱SVG等で描画し、外部画像・フォント・実行時APIに依存しない。新しい描画・幾何ライブラリーの追加は初版の前提にしない。
- 個人情報・ログイン・外部への回答送信を追加しない。静的ビルドまでを対象とし、公開先へのデプロイは含めない。
- 教材の全45問について、正解の一意性・特徴説明・見た目を確認した日本語の教材確認記録を残す。

# 対象外

- 合同・相似という用語を覚えることの試験、長さや角度の数値計算、作図、ドラッグでの回転操作。
- 立体、楕円・多角形を新たな学習題材にすること、曲線を含む複合図の数え上げ。
- 正三角形・二等辺三角形・直角三角形のいずれにも当てはまらない三角形を使う応用問題、6題材以外の種類を指定して数える問題、自由な画像のアップロードと認識。
- 問題の自動生成、制限時間、ランキング、ログイン、端末間同期、途中再開、公開環境へのデプロイ。
- 既存4ゲームの学習内容や報酬の作り直し。

# リスクと対応

| リスク | 対応 |
| --- | --- |
| 基本編と応用編で大きさの扱いが違う | 開始前の説明を分け、モード名と問題文で条件を示す |
| 種類の名称だけで基本編を採点してしまう | 寸法と回転による一致を検証し、同種の大きさ違いを必ず不正解候補にする |
| 自動フィットで大きさ違いが消える | 同じ描画枠と座標尺度を使い、3画面幅で実表示を確認する |
| 合成図の正解輪郭に抜け・重複が出る | 輪郭一覧を描画データから独立して照合する自動検証と、全教材の目視確認を行う |
| 正方形と長方形等の重なりを誤って教える | 条件の重なりを否定せず、応用編では指定した種類の条件を満たすすべての輪郭を数える。重なりがある問題では数える規則を説明する |
| 複合図の中に範囲外の三角形が生まれる | 正解輪郭だけでなく、交点と辺の組み合わせからできる全三角形を確認し、対象3種類のいずれにも当てはまらないものを持つ図を採用しない |
| 共通の宝物区分への追加が漢字側に影響する | 両方の帳面でIDを対象アプリに限定し、既存保存データと共存させて確認する |
