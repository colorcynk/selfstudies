# 背景と目的

小学生がゲーム感覚で楽しみながら学習できるWebアプリを、今後も追加していくプロジェクト。初版では小学2〜3年生を主な対象に、次の4つを実際に遊べる状態まで作る。

1. 九九モンスター図鑑
2. お買いものクエスト
3. 漢字探検隊
4. 100ます計算

共通ホームの仮称は「まなびのゲームひろば」。4つは別々の遊び方を持つが、1つのWebプロジェクトにまとめ、起動方法と画面の操作を共通化する。

# 対象と成功の目安

- 主な利用者：小学2〜3年生。保護者が最初の操作を手伝う場合も想定する。
- 学年は利用制限にせず、九九の段・問題の種類・問題数を選べるようにする。
- ホームから遊びを選び、説明を読み、回答し、結果と報酬を確認して再び遊べる。
- 短いモードは数分で区切れる。100ます全部を解く時間には一律の制限を設けない。
- 間違えた場合もヒントを見て再挑戦でき、残機・ゲームオーバー・連続利用の罰則を設けない。

# 初版の範囲

## 教材の根拠

- 九九は小学2年生の算数の内容に含まれる。初版では1桁同士の計算を中心とし、買い物では2桁の足し引きを入口に、3年生も遊べる3桁の計算を後の依頼に配置する。[^mext-mathematics]
- 買い物と100ますは、本アプリが採用するゲーム・練習形式であり、学習指導要領で必須とされる形式という扱いにはしない。
- 学年別漢字配当表では2年生160字、3年生200字が配当されている。初版はその一部から読みと使い方を練習する問題を選ぶ。[^mext-japanese]

## アプリ間の学習の役割

- 九九モンスター図鑑：九九を覚える入口。図鑑完成後も同じ内容を練習できる。
- お買いものクエスト：九九で学んだかけ算を、個数や金額を求める具体的な場面で使う。
- 100ます計算：段の順番に頼らず、正確に答える練習。10問モードでも掛け算を選べる。
- 漢字探検隊：通常の読み・使い方に加え、同じ漢字の読みを文脈で区別する練習。

[^mext-mathematics]: [文部科学省 小学校学習指導要領解説 算数編](https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf)
[^mext-japanese]: [文部科学省 小学校学習指導要領解説 国語編・学年別漢字配当表](https://www.mext.go.jp/content/20220606-mxt_kyoiku02-100002607_002.pdf)

## 1. 九九モンスター図鑑

### 遊び方

1. 1〜9の段から生息地を選ぶ。
2. 選んだ段の九九を9問解く。掛ける数1〜9を重複なく出し、順番を入れ替える。
3. 全問に正しく答えると、その段のモンスターが仲間になる。
4. 図鑑で仲間と段ごとの練習結果を確認する。

### 要件と完成条件

- 数字入力と画面内の数字ボタンで回答できる。
- 間違えた問題は足し算のまとまりなどのヒントを出し、同じ問題を再挑戦する。
- 段ごとに異なる見た目・名前のモンスターを9体用意する。
- 途中で離れても獲得済みモンスターは失われない。途中の問題は再開対象にしない。
- 9問を終える前に仲間は獲得されない。再クリアしても図鑑には同じモンスターを重複登録しない。
- 既に仲間にした段も何度でも練習できる。

## 2. お買いものクエスト

### 遊び方

1. 商店街で依頼を選ぶ。
2. 買い物リストを読み、商品を選んでかごに入れる。
3. 合計金額とおつりを答えて依頼を達成する。
4. 達成した依頼にスタンプが付く。

### 要件と完成条件

- 6つ以上の固定クエストと、8種類以上の商品を用意する。
- 通常の依頼は「商品選択」「合計」「おつり」の3段階で構成する。
- 6つ以上の依頼のうち2つ以上をかけ算の実践にし、「商品選択」「かけ算の実践問題」「合計」「おつり」の4段階で構成する。
- かけ算の実践には「1袋に5個入ったアメを3袋買うと、全部で何個？」のような1桁同士の個数の問題と、「1個30円の商品を3個買うと何円？」のような金額の問題をそれぞれ1つ以上含める。
- はじめの依頼は品数を少なくし、後の依頼で同じ商品を複数買う計算を入れる。
- 金額は整数の円とし、初版は1,000円以内、品物の合計が支払金額を超えない問題にする。
- かごの中身と個数を見られ、取り消し・変更ができる。
- 正しい商品と個数が揃うまで合計問題に進めない。
- 合計問題ではかごの合計金額を答えとして先に表示しない。
- ヒントは品物ごとの足し算、おつりの引き算を示す。かけ算の実践では「いくつずつ、いくつ分」と式の対応を示す。
- 間違えてもかごは失われず、達成済みの依頼も再挑戦できる。

## 3. 漢字探検隊

### 遊び方

1. 通常の探検では「2年生のことば」「3年生のことば」から探検する場所を選ぶ。追加モードとして「よみわけ探検」も選べる。
2. 看板の読みや、文に合う漢字を選んで扉を開く。
3. 5問の探検を終えると宝物を獲得する。
4. 宝物帳とクリアした探検を見られる。

### 要件と完成条件

- 通常の探検は各学年20問以上、合計40問以上の手作成問題を用意する。各学年に読みと文中の使い方の両方を含める。よみわけ探検の問題は、この40問とは別に用意する。
- 教材の文章は独自に作成する。各問題に安定したID・対象学年・問題文・選択肢・正解・ヒントを持たせる。
- 問題にする漢字の配当学年は、公的な学年別漢字配当表に照合する。
- 読みの問題は文脈を付けて読みを一意にし、選択肢は異なる4つとする。
- 使い方の問題は短い文の空欄に合う漢字・ことばを4択で選ぶ。
- 1回の探検で同じ問題を重複出題しない。各学年4つ以上の5問ステージを用意する。
- 間違えた場合はことばの意味などのヒントを出し、同じ問題に再挑戦する。
- 全5問を終えた探検だけ宝物を獲得する。同じ探検の再クリアで宝物を重複登録しない。
- 手書き認識・書き順判定は初版に含めない。

### 追加モード：よみわけ探検

#### 初版の範囲

- 同じ漢字が異なる読みで2回登場する、自然な短い文章を5〜10文用意する。1文を1問とし、1回の探検は重複しない5文で構成する。
- 読む問題に限定し、文章内の2か所をそれぞれ選択式で回答する。各箇所に異なる4つの読みの選択肢を用意し、正解はひらがなで表す。
- 対象漢字は1〜3年生の配当漢字から選び、読みや語句も小学2〜3年生が理解できるものを手作成する。対象外の漢字には必要に応じてふりがなを付け、回答する箇所の読みは表示しない。
- 文全体の読みの入力、漢字への変換入力、手書き判定は初版の追加モードに含めない。「書く」問題は次の拡張候補とする。
- 通常の探検をクリアする前でも選べる。探検隊の説明と宝物帳を共通に使う。

#### 出題データと採点

- 各文に安定した問題ID・対象学年・文の表示用データを持たせ、回答対象の2か所を表示用データ内で明示する。同じ漢字を文中から自動検索する方法には依存しない。
- 回答箇所ごとにID・対象漢字・読みの選択肢・正解・文脈に合ったヒントを持たせる。2か所の対象漢字は同一、正解の読みは異なるものとする。
- 2か所を選んで答え合わせすると、それぞれの正誤を文字で示す。両方に正しく答えるまで次の文へ進まない。
- 一方だけ間違えた場合、正解済みの選択は保持して変更不可にし、間違えた箇所だけヒントを見て再挑戦できる。
- 初回正答数は文単位で集計し、初回の答え合わせで2か所とも正解した文だけを初回正解に数える。再挑戦しても初回正答数は増えない。
- 全5文の両方の箇所に正しく答えると、よみわけ探検専用の宝物を獲得する。通常の宝物とIDを分け、再クリアで同じ宝物を重複登録しない。
- 保存する完了記録にモードを含め、通常の探検とよみわけ探検を区別できるようにする。途中離脱では宝物や完了記録を追加しない。

#### 完成条件

- 5〜10文すべてで、同じ漢字の2つの読みを文脈から一意に決められることを教材確認で記録する。
- 1回5文で重複出題がなく、2か所の回答・採点・片方だけの再挑戦・完了が行える。
- 正解の保持、初回正答数、宝物の重複防止、モード別の完了記録を確認する。

## 4. 100ます計算

### 遊び方

1. 足し算・引き算・掛け算を選ぶ。
2. 10問・25ます・100ますから量を選ぶ。
3. 行と列の数字を計算して各マスに答えを入れる。
4. 答え合わせと直しを終え、結果を確認する。

### 要件と完成条件

- 10問は2行×5列、25ますは5行×5列、100ますは10行×10列の表とする。
- 足し算・掛け算の見出しは0〜9から生成する。10個の見出しがある軸は0〜9を1回ずつ使い、短い軸も重複させない。
- 引き算は行の数字10〜19から列の数字0〜9を引き、負の答えを出さない。
- 行・列の見出しを区別し、引き算の向きを説明する。
- 未入力と0を区別する。負数・小数・数字以外は正しい回答として扱わない。
- 答え合わせは全マス入力後に行い、間違えたマスだけ直せる。正しいマスの回答は保持する。
- 各入力に行・列・計算式を含むラベルを付け、Enterで次のマスへ移動できる。
- スマートフォンでは表を横にスクロールでき、見出しと選択中のマスを見失いにくくする。
- 計時は開始前に選べ、初期値は時間を気にしない練習モード。制限時間や強制終了は設けない。
- 計時の有無にかかわらず初回正答数を記録する。全問初回正解の計時あり結果だけを自己ベスト候補にする。
- 自己ベストは計算種類と問題数の組み合わせ別に保存する。
- 途中離脱した回は完成記録や自己ベストに追加しない。
- 100ますは短いゲームの時間目安の対象外とする。

# 画面構成とデータ

## 画面

- 共通ホーム：4つの入口、遊び方の紹介、獲得したものの概要。
- 各アプリ：選択画面、ゲーム画面、結果画面。
- 収集画面：モンスター図鑑、宝物帳。各アプリから開く。
- 設定：端末内保存の説明と記録の消去。
- URLで各アプリを区別し、戻る操作と再読み込みで不正な状態にならない。遊び途中の再読み込みは選択画面に戻る。

## 保存

- 1ブラウザにつき1人分を想定する。氏名・メール・学校・生年月日は入力させない。
- 完了した回の概要、モンスター、宝物、クエスト達成、自己ベストをlocalStorageへ保存する。
- 保存形式にバージョン番号を付け、読み取り時に値を検証する。直近の学習履歴は最大50回分とする。
- 問題データとイラストはアプリに同梱し、回答や記録を外部サービスに送信しない。
- 保存内容は同じ端末・同じブラウザ内に限る。ブラウザのデータ削除では記録が失われることを設定画面で説明する。

# 技術・運用の提案

- 現在のフォルダには既存アプリがないため、初版はReact・TypeScript・Viteによる静的なフロントエンドを候補とする。
- Vite公式資料にReact・TypeScript用テンプレートと静的ビルドの案内があり、現在のNode.js v24.18.0は記載されたNode要件を満たす。[^vite-guide]
- Bunをパッケージ管理とスクリプト実行に使う。依存関係の確定は実装計画時に行う。
- アプリごとにコード・問題データを分け、問題生成・採点・保存処理は表示から分離する。
- イラストは独自のSVGなどで同梱し、外部画像・外部フォントの配信に依存しない。
- ローカル起動方法、確認コマンド、保存の仕様、問題を追加する方法を日本語READMEへ記載する。
- 公開先へのデプロイは今回の範囲外。静的配信できるビルド成果物を作る。

[^vite-guide]: [Vite Getting Started](https://vite.dev/guide/)

# 対象外

- ログイン、複数プロフィール、端末間同期、教師向け管理画面。
- 広告、課金、他の子とのランキング、チャット。
- AIによる実行時の問題生成、音声読み上げ、手書き漢字認識。
- よみわけ探検での文全体の読みの入力、漢字への変換入力、書き取り問題。
- 学年の全範囲を網羅する教材、学習効果の保証。
- 途中問題の保存・再開、通信のない状態での初回起動を保証するPWA対応。

# 検証と受け入れ条件

1. 4アプリすべてで「選択→回答→間違いとヒント→再挑戦→完了→記録確認→ホーム」の流れをブラウザで確認する。
2. 再読み込み後も完了済みの収集と記録が残り、未完了の回は報酬にならない。
3. 九九の9問、買い物のかけ算・合計・おつり、100ますの生成・採点が正しいことを自動テストで確認する。
4. 通常の漢字問題とよみわけ問題について、件数、4択の重複、正解の存在、IDの重複、学年の値を検証し、内容と学年の照合を記録する。よみわけ問題は1文に回答箇所が2つあり、同じ漢字で異なる読みになることも検証する。
5. 保存データの欠損・破損・保存禁止、操作の連打、0の回答、同じ収集の再獲得を確認する。
6. 375px・768px・1280pxで主要画面を確認し、タッチ・キーボードの操作を確認する。
7. 型検査・適切な自動テスト・本番ビルドが成功する。実際に実行した確認と未実施の確認を区別して報告する。
8. よみわけ探検で両方正解・片方だけ誤答・両方誤答を確認し、再挑戦後も文単位の初回正答数が正しく、通常の宝物と区別して保存されることを確認する。

# 制約・リスクと対応

| 項目 | 対応 |
| --- | --- |
| 子どもごとに学習経験が異なる | 学年で利用を制限せず、段や問題数を自分で選べる |
| 漢字の読みや文の解釈が曖昧になる | 文脈を付けた手作成問題と、教材内容の確認を行う |
| 100ますの表が小さい端末では大きい | 短いモードとスクロール可能な表を用意する |
| 保存が使えない・壊れる | データ検証と、その場で遊べる代替動作を用意する |
| 端末を共有する場合に記録が混ざる | 初版は1ブラウザ1人分であることを明記する |
| 有効なGitリポジトリがない | コミットを前提としない一括実装を提案する。Gitの初期化やコミットは別途明示的に選択された場合のみ行う |
