# 漢字教材の内容確認記録

確認対象: 2026-10-09 作成の初版40問と、追加モード5文。通常問題のID・設問・選択肢・答え・ヒントは `src/apps/kanji/data/normal.ts`、よみわけ文は `src/apps/kanji/data/readingDifference.ts` にある。文章はすべてこの教材用に作成した。

## 配当学年の根拠

対象字の学年は、文部科学省「小学校学習指導要領（平成29年告示）解説 外国語活動・外国語編」付録9「学年別漢字配当表」を照合した。公式PDFの閲覧188ページにある学年別配当表を使った（印刷頁は記載しない）。[文部科学省・小学校学習指導要領（平成29年告示）解説 外国語活動・外国語編（PDF、付録9・閲覧188ページ）](https://www.mext.go.jp/content/20220614-mxt_kyoiku02-100002607_11.pdf#page=188)。

通常問題は20問ずつ、各学年4ステージ（ID `kanji:g2-01`〜`g2-04`、`kanji:g3-01`〜`g3-04`）に5問。全ステージに読みと文中使用の両方が含まれる。各問は4つの異なる選択肢を持つ。初版確認では文脈上の正解が一つという判断が不十分で、独立最終評価で通常問題3問に別の自然な完成が見つかったため、下記の実装レビューで文脈を修正した。全対象字は出題対象学年と同じ学年に配当されている。2年生19問目の「黄」は「黄色」の読みを問う対象字、20問目の「汽」は「汽車」の使い方を問う対象字。問題文・ヒント・選択肢中の対象外漢字も各設問の出題学年までの配当字に限定し、より難しい語はかなにした。

## 採点・カタログ確認

通常ステージはT2の8つのカタログIDと各5問に一致する。読み分けはT2の専用ID・5文に一致する。ドメインテストで通常40件・8ステージ、各4択の重複なし、全問の答えが選択肢にあること、差分5文の二つの対象ID・同字・異なる読み、初回の両正解のみ文単位加点、正解済み箇所のロックと誤答箇所の再挑戦を確認する。

## 実装レビュー（2026-10-13）

独立最終評価で、通常問題の文脈に複数の自然な完成がある3問を指摘されたため、次のように局所修正した。対象字、正解、ID、学年、問題数、ステージ構成は維持している。

| ID | 修正 | 文脈上の意図 |
|---|---|---|
| kanji-g2-q18 | かばんの性質を並べる文から、「どんなに引っぱっても切れないほど＿＿い」へ変更 | ひもが切れにくい力強さを表し、「細い」などの別属性が答えになる余地をなくす |
| kanji-g3-q04 | 選択肢「医」を、配当済みの「校」に変更 | 「医院」という別の自然な語を選択肢から除く |
| kanji-g3-q12 | 選択肢「物」を、3年配当の「駅」に変更 | 「あたたかい物を着る」という別の自然な完成を選択肢から除く |

修正後も4択は重複せず、正解は対象字のまま。この節は実装担当による修正内容と当時の文脈レビューを記録している。5つのよみわけ文は変更していない。「木の下」の「下」を「した」と読む点は大辞泉を確認済みで、修正対象ではない。独立再監査の結果は次節に記録する。

## 独立再監査（2026-10-13）

独立検証担当が修正後の通常問題40問と、よみわけ探検5文（対象箇所10か所）を読み、全選択肢を文脈に当てて再確認した。今回修正した3問の別解は解消し、ほかに明白な意味上の問題は見つからなかった。各問題の選択肢の重複、文脈上の正解の一意性、対象字の学年条件を確認した。よみわけの対象箇所・読み・正解関係も維持されている。さらに別の調査担当が、平成29年告示資料の現行配当表に通常問題40件の対象字と、よみわけ5文の対象字（5件）を照合し、計45件すべて一致することを確認した。既存ドメインテスト5件と型検査も成功した。問題データ、問題数、ステージ・モード構成はこの監査では変更していない。

修正で追加した対象外漢字の配当も、同じ平成29年告示資料の付録9で直接確認した。「引」「切」は2年、「校」は1年、「駅」は3年に配当されている（閲覧188ページ、印刷頁は不記載）。平成20年2月の「小学校学習指導要領案」でも同じ配当を確認していたが、これは告示前の案であるため、現行の学年配当の根拠は上記平成29年告示資料とする。[文部科学省・小学校学習指導要領案（平成20年2月、PDF、閲覧30–31ページ／印刷21–22ページ）](https://www.mext.go.jp/a_menu/shotou/new-cs/news/080216/002.pdf)。
